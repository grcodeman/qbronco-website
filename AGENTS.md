# Instructions for coding agents

This repo's instructions for AI coding agents live in [CLAUDE.md](CLAUDE.md), and they apply to every agent, not just Claude. Read it before changing anything, especially two sections:

- **"Tests: update them with the code":** find the tests your change affects and update them in the same commit. CI runs them on every PR.
- **"Show visible changes":** before/after screenshots for anything people will see.
